# system_map.md# Live Architectural Map - TrumpetNotes PWA## 1. Domain Object Hierarchy (OOP Engine)[PitchClass] (Enum: C, Db, D, Eb, E, F, Gb, G, Ab, A, Bb, B)│▼[Note] ───────────────► [Accidental] (NATURAL, SHARP, FLAT)│├── implements Comparable└── properties: rawInput, pitchIndex (0-11), octave (optional)│▼[MusicalParser] ─────────► Uses Strategy Pattern:│                    ├── LatinNotationStrategy ("Do, Re, Mi...")│                    └── EnglishNotationStrategy ("C, D, E...")▼[ScaleEngine] ───────────► Matches pitch frequencies to 24 Major/Minor scales│▼[KeyDetector] ───────────► Evaluates root key & mode (Trumpet Key vs Concert Key)│▼[TranspositionEngine] ───► Applies chromatic interval shifting (-2 semitones)## 2. Firebase & Firestore Data Model (Strict Even-Segment Paths)- Base Route: `users/{userId}`  - Collection: `users/{userId}/notes/{noteId}`    - Document Schema:      ```json      {        "id": "string",        "title": "string",        "rawContent": "string",        "parsedNotes": ["string"],        "trumpetKey": "string",        "concertKey": "string",        "transposedContent": "string",        "tempoBpm": 120,        "createdAt": "timestamp",        "updatedAt": "timestamp"      }      ```  - Collection: `users/{userId}/preferences/appConfig`    - Document Schema: `{ "defaultNotation": "LATIN" | "ENGLISH", "theme": "system" }`## 3. PWA & Service Worker Topology- `manifest.json`: Display `standalone`, orientation `portrait`, icons 192x192 & 512x512.- `sw.js`:  - Static Precache: App shell (HTML, CSS tokens, JS bundle, Web Audio buffers).  - Runtime Cache: Google Fonts, static iconography.  - IndexedDB Persistence: Handled via `@firebase/firestore` native indexeddb cache layer.## 4. UI Layer Routing (Mobile-First Sheet & View Layout)- `/` -> `NotesListView` (Search bar, note grid/list cards, FAB for new note)- `/note/:id` -> `NoteEditorView` (Textarea note pad, dual key pills, floating transpose view switch)- `/tools/tuner` -> `ReferenceToneModal` (Quick 440Hz / Bb reference player)
